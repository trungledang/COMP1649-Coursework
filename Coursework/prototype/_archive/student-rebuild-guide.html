Hướng dẫn TỰ TAY dựng prototype Axure RP 11

Phạm vi: 8 trang, 3 journeys khớp 3 RQ. Thời gian dự kiến ~3–4 giờ. Đây là tài liệu hỗ trợ học tập/planning — bạn tự dựng, tự quyết định chi tiết cuối cùng, và những quyết định đó chính là nội dung bạn viết trong report (mục 3 & 4).

Vì sao phải tự dựng: các file studyflow-*.rp là bản AI-built để luyện tập (file status tự ghi rõ không phải bản nộp). Nộp file đó = vi phạm quy chế AI trong brief. Cách an toàn duy nhất: bạn dựng file mới của mình theo hướng dẫn này, và dùng bản cũ làm tham khảo về bố cục. Khi tự dựng, hãy chụp ảnh từng bản nháp (File → Save As ra v1, v2, v3…) — đây là bằng chứng "design process" mà mục 3.1 của report cần.

Quy trình làm cuối cùng

  1. Axure RP 11 → New File. Project → Global Variables → tạo 6 biến như bảng.
  2. Làm theo hướng dẫn từng trang 1→8, mỗi trang xong File → Save As thành coursework-prototype-v1.rp, …-v2.rp… (bản cuối dùng để nộp). Mỗi version ghi file-note xuống iterations-log.md bạn tự viết: "v2: added support flow panel, fixed Save not persisting day".
  3. Preview (phím F5) ngay sau mỗi 2 trang — chưa từng được làm ở mọi bản cũ; đây là việc chỉ bạn có thể làm vì cần môi trường Axure thật.
  4. Khi dựng xong cả 8 trang: đi lại toàn bộ 3 journeys bằng "Example test activity" đã ghi trong task-05-research-questions-draft.md.
  5. Chụp screenshots dùng cho report mục 3.2 (Norman) và mục 4 (prototype).

Tài liệu hỗ trợ học tập/planning theo quy chế AI của brief. Bạn tự thao tác trong Axure, tự diễn đạt mọi nội dung report. File này KHÔNG phải là nội dung coursework nộp.
